# 错误处理模块测试说明

本文档描述了 `error_handler.sh` 模块的单元测试。

## 📁 测试文件

- `test_error_handler.sh` - 主要的测试脚本
- `run_error_handler_tests.sh` - 测试运行器
- `README_error_handler_tests.md` - 本文档

## 🚀 快速开始

### 运行所有测试
```bash
cd datakit-automation/test/core
bash run_error_handler_tests.sh
```

### 直接运行测试脚本
```bash
cd datakit-automation/test/core
bash test_error_handler.sh
```

## 🧪 测试覆盖范围

### 1. 函数存在性测试
- `get_error_code` - 根据错误名称获取错误代码
- `get_error_severity` - 根据严重程度名称获取数值
- `init_error_handler` - 初始化错误处理器
- `handle_error_signal` - 信号处理
- `cleanup_on_exit` - 退出清理
- `cleanup_temp_files` - 清理临时文件
- `cleanup_log_files` - 清理日志文件
- `record_error` - 记录错误
- `handle_error` - 标准错误处理函数
- `die` - 标准化的die函数
- `check_error` - 标准化的错误检查函数

### 2. 功能测试

#### 错误代码查询测试
- 测试所有预定义的错误代码
- 测试不存在的错误代码（返回默认值）
- 测试所有预定义的严重程度
- 测试不存在的严重程度（返回默认值）

#### 错误记录测试
- 测试记录不同级别的错误（ERROR、WARNING、INFO）
- 测试默认严重程度设置
- 测试错误消息格式

#### 错误处理测试
- 测试ERROR级别错误处理（返回错误码）
- 测试WARNING级别错误处理（返回成功）
- 测试INFO级别错误处理（返回成功）

#### 错误检查测试
- 测试成功情况（退出码为0）
- 测试失败情况（退出码非0）

#### 清理功能测试
- 测试清理临时文件函数
- 测试清理日志文件函数
- 测试退出清理函数

#### 信号处理测试
- 测试INT信号处理（用户中断）
- 测试TERM信号处理（系统终止）
- 测试未知信号处理

#### 初始化测试
- 测试错误处理器初始化

## 🔧 测试环境

### 模拟函数
测试使用模拟函数来避免对实际系统的影响：

- `mock_log_info()` - 模拟信息日志
- `mock_log_warning()` - 模拟警告日志
- `mock_log_error()` - 模拟错误日志
- `mock_log_debug()` - 模拟调试日志
- `mock_command()` - 模拟命令检查
- `mock_find()` - 模拟文件查找和删除

### 测试文件
测试会创建以下测试文件：
- 临时测试文件（用于测试清理功能）
- 测试日志文件（用于验证日志输出）
- 模拟日志目录结构

## 📊 测试结果

### 输出格式
测试结果包含：
- 测试名称和描述
- 通过/失败/跳过状态
- 详细的错误信息
- 测试统计摘要

### 结果文件
测试完成后会生成：
- `.log` 文件 - 详细的测试日志
- `.json` 文件 - 结构化的测试报告

## 🐛 故障排除

### 常见问题

1. **权限问题**
   ```bash
   chmod +x test_error_handler.sh
   chmod +x run_error_handler_tests.sh
   ```

2. **路径问题**
   确保在正确的目录下运行测试，或者使用绝对路径。

3. **依赖问题**
   测试脚本依赖bash shell，确保系统支持bash。

4. **模拟函数问题**
   如果测试失败，检查模拟函数是否正确实现。

### 调试模式
如果需要调试测试，可以在测试脚本中添加：
```bash
set -x  # 启用调试模式
```

## 🔍 测试注意事项

### 信号处理测试
- 信号处理测试不会实际发送信号，只是测试函数调用
- 某些函数（如`die`）会调用`exit`，测试中会模拟这些行为

### 清理函数测试
- 清理函数测试使用模拟的文件系统操作
- 不会实际删除系统文件

### 错误代码测试
- 错误代码测试验证预定义的错误代码映射
- 包括边界情况（如未知错误代码）
