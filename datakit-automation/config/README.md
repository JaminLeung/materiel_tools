# Datakit 配置文件架构

## 概述

本目录包含了 Datakit 自动化部署系统的配置文件架构，采用分层设计，支持环境隔离、脚本特定配置和运行时状态管理。

## 目录结构

```
config/
├── base/                    # 基础配置
│   ├── base_config.sh      # 核心基础配置
│   └── state_config.sh     # 运行时状态管理配置
├── env/                     # 环境配置
│   ├── example.sh          # 示例环境配置
│   ├── development.sh      # 开发环境配置
│   ├── production.sh       # 生产环境配置
│   └── benjamin.sh         # Benjamin环境配置
├── scripts/                 # 脚本特定配置
│   ├── config_update.sh    # Config Update脚本配置
│   ├── app_init.sh         # App Init脚本配置
│   └── health_check.sh     # Health Check脚本配置
├── loader.sh               # 配置加载器
└── README.md               # 本文档
```

## 配置层次结构

### 1. 基础配置 (base_config.sh)
- **职责**: 提供系统的基础配置和默认值
- **内容**: 
  - 脚本元信息
  - 基础路径配置
  - 基础环境配置（可被覆盖）
  - 安装路径配置
  - 通用配置（日志、备份、错误处理等）
- **特点**: 不包含特定脚本的配置，只提供通用基础

### 2. 状态配置 (state_config.sh)
- **职责**: 管理脚本运行时的状态变量和状态管理函数
- **内容**:
  - 全局状态变量（主机IP、环境、工作空间等）
  - 脚本状态变量（开始时间、当前步骤、错误信息等）
  - 性能监控变量（下载时间、安装时间等）
  - 安装状态变量（安装状态、服务状态等）
  - 状态管理函数（初始化、更新、完成等）
- **特点**: 提供运行时状态跟踪和管理功能

### 3. 环境配置 (env/*.sh)
- **职责**: 根据不同的部署环境提供特定配置
- **内容**:
  - 环境标识
  - 环境特定的配置值
  - 脚本特定配置的覆盖值
- **特点**: 可以覆盖基础配置，支持环境隔离

### 4. 脚本特定配置 (scripts/*.sh)
- **职责**: 为特定脚本提供专用配置
- **内容**:
  - 脚本基本信息
  - 脚本特定的路径配置
  - 脚本特定的功能配置
- **特点**: 继承基础配置，可以引用环境配置

## 配置加载顺序

配置加载遵循以下优先级顺序（从高到低）：

1. **环境变量** (最高优先级)
2. **脚本特定配置**
3. **环境配置**
4. **状态配置**
5. **基础配置** (最低优先级)
